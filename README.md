# 🇻🇳 VietVerse

VietVerse is a Vietnamese online game hub foundation. This repository starts the V2 full-stack rebuild.

## V2 roadmap
- Modern responsive lobby UI
- Email + 6-digit OTP verification
- Secure session authentication
- Discord OAuth
- Avatar editor and inventory
- Coins, XP, levels and leaderboard
- Persistent announcements and admin panel
- Multiplayer-ready game/lobby architecture
- Mobile + desktop support

## Security
Never commit API keys, OAuth client secrets, database credentials, or session secrets. Configure them through the deployment provider's environment variables.
